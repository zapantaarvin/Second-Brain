# Business/10_Projects

Business ventures with a finish line or a clear active initiative — e.g. "Launch FFN protein bar site," "Zapee Q1 supplier contracts."

- One note per venture or initiative.
- When a project ends, move its notes to `Business/40_Archive`.
- If something never actually finishes, it's probably an Area, not a Project — move it to `Business/20_Areas`.
