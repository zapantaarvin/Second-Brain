# CLAUDE.md — Projects (app building)

Loaded automatically once Claude reads or edits a file inside `Projects/`. See the root `CLAUDE.md` for vault-wide rules — this file only adds what's specific to this category.

## What belongs here
Apps Arvin is personally coding — distinct from `Business/`, which holds venture strategy/ops for businesses with no dev artifact of their own.

## Business vs. Projects — the litmus test
**Does this have its own repo, tech stack, and build-phase status that Arvin is personally developing?**
- Yes → `Projects` (e.g. Kanban Business Hub: Next.js/Supabase, own `CLAUDE.md`/`AGENTS.md`, build phase tracked; Financial Compass App: own repo, in-testing status)
- No — it's venture strategy/ops/market reference with no dev artifact → `Business` (e.g. Zapee, Protein Bar Business/FFN — both planning-stage, no app)

If a business later gets its own app built for it, the app note goes here in `Projects` even if the business note itself stays in `Business` — they can cross-link rather than merge.

## Vault ≠ codebase
This vault holds status/reference notes about each app — not the app's own source, task board, or `CLAUDE.md`. Link out to the app's own repo instead of duplicating its structure here (same principle as the `Business/CLAUDE.md` "vault ≠ task tracker" rule).
