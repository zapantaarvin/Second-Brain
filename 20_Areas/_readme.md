# 20_Areas

Ongoing responsibilities with **no finish line** — standards you maintain over time, not projects you complete. E.g. "Investing," "Health," "Business Ops," "Career."

- Review periodically, not project-style tracked to completion.
- A Project often lives inside an Area (e.g. "Launch FFN bars" is a Project under the "Business Ops" Area) — link them with `[[wikilinks]]` rather than nesting folders.
