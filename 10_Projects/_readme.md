# 10_Projects

Things with a **finish line** and a deadline or clear end-state — e.g. "Launch FFN protein bar site," "Close home purchase," "Plan Japan trip."

- One subfolder or note per project.
- When a project ends, move its notes to `40_Archive`.
- If something never actually finishes, it's probably an Area, not a Project — move it to `20_Areas`.
