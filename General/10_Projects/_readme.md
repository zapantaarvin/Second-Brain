# General/10_Projects

Things with a **finish line** that don't belong to School, Projects (app-building), or Business — e.g. "Build the Skills-library audit tracker."

- One subfolder or note per project.
- When a project ends, move its notes to `General/40_Archive`.
- If something never actually finishes, it's probably an Area, not a Project — move it to `General/20_Areas`.
