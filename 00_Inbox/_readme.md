# 00_Inbox

Capture everything here first. No filtering, no categorizing, no folder decisions at capture time — that friction is what kills the habit.

- One note per thought, link, or idea. Doesn't need a title that makes sense yet.
- Process during your weekly review: move each note into `10_Projects`, `20_Areas`, or `30_Resources`, or delete it if it's dead.
- If a note has sat here longer than two weeks, that's a signal — either act on it or archive it.
